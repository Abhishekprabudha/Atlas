# Operational Workflow Guide

## Outbound workflow

- Confirm acceptance, build-up and ramp execution against LMS milestones.
- Review cargo status, media location and task ownership as workflow events arrive.

## Inbound workflow

- Validate ramp check-in, breakdown, storage and release controls.
- Review PRP holding and TTS cold-room routing.

## Maintenance workflow

- Review equipment availability, service windows and open maintenance incidents.
- Confirm alternate routing and recovery evidence before returning equipment to service.

## Integration workflow

- Monitor command acknowledgement, idempotency and error-queue status.
- Replay a preserved message only after the gateway is available.
